# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Проєкт

«Стежинка до читання» - застосунок для телефона, з яким дитина вчиться читати українською.
Бекенду немає: прогрес і записи голосу зберігаються лише на пристрої.
Інтерфейс, коментарі в коді й повідомлення комітів - українською.
Коміти описують зміну з погляду користувача, а не технічно.
Методика й порядок букв детально описані в `README.md`.

## Будова

- Навчальний контент (букви, слова, план місій) - це лише дані, без інтерфейсу.
  Нову вправу чи місію додають у контент, не змінюючи компонентів.
- Логіка (прогрес, повторення, генерація вправ) - чисті функції без інтерфейсу; випадковість детермінована через seed, щоб її можна було тестувати.
- Інтерфейс лише показує вправи й передає результати в логіку.
- Тести перевіряють і методику контенту (слова лише з уже вивчених букв, порядок складності).
  Якщо такий тест падає після зміни контенту, зазвичай виправляти треба контент, а не тест.
- Згенеровані файли (позначені в першому рядку) вручну не редагують - їх оновлює відповідний скрипт.

## Сумісність зі збереженим прогресом

У дітей на телефонах уже є збережений прогрес, і його не можна втратити.
- Будь-яка зміна формату стану має коректно читати старі збереження.
- Ідентифікатори місій не залежать від їхнього місця в плані; перейменовуючи ідентифікатор, старий треба зберегти як відповідник нового.
- Застосунок працює офлайн: змінюючи кешування, переконайтеся, що старі версії не залишаться в телефоні назавжди.

## Принципи методики (не порушувати)

- Звуки, а не назви букв («[м]», а не «ем»).
  Тому синтезатора мовлення немає: усе звучить живим голосом - спершу запис дорослого, якщо він є, інакше вбудований.
- Жодних таймерів, балів, «неправильних» звуків; зароблені нагороди ніколи не забираються.
- Склади читаються злито, а не по буквах.
- Голосні червоні, приголосні сині - крім вправ на впізнавання букви, де колір не має підказувати.
- Картинка до слова з'являється лише після читання; прослуховування запису рахується як підказка.
- Підказки поступові: спершу натяк, потім правильна відповідь.
- Автоматичної оцінки вимови немає: читання вголос відмічає дорослий, а коли дитина грається сама, вправи перевіряються без вимови.
